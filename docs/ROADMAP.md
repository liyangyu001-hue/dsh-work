# 路线图

> 每一阶段都有：**能演示的东西** + **可验收的标准** + **退出条件**。
> 任何一阶段不满足退出条件，不允许开始下一阶段——这是防止屎山的闸门。

---

## P0 · 地基（已完成 2026-10-19）

**能演示**：插件装进 DSH 后，窗口内出现一条静态玻璃条，显示一个硬编码任务；伴随层起来后能与之握手，热键能触发框选。

**验收**
- [x] `pnpm test` 全绿（39 个用例）；`tsc --noEmit` 干净
- [x] `docs/` 五份文档齐备，PROTOCOL v1 冻结
- [x] 插件能通过本地路径装进 profile 并被加载（沿用 `link:` 依赖）
- [x] `GET /dsh-work/api/health` 返回 200
- [x] 伴随层能连上宿主、接收 `snapshot` 事件、断线后按 1/2/5/10s 退避重连
- [x] 首次 git 提交，提交信息说明改了什么

**P0 实际交付（比计划多的部分）**
- 系统级置顶玻璃条（Electron 无边框透明窗 + `alwaysOnTop("screen-saver")` + 状态回放），真机截图为证：`docs/assets/bar-p0.png`
- 宿主侧任务状态机 + 只追加日志 + 快照，**杀进程重启后状态完整**（真机验收）
- 窗口内玻璃条挂在 `shell.overlay`，走同源 `/dsh-work/api/*`，与伴随层共用同一份状态编排
- 伴随层日志 `~/.dsh/dsh-work/companion.log`（用户报障唯一凭证，切日志时删一次即可）

**退出条件**：三端"活着并互相认得"，不要求任何智能。✅

## P1 · 闭环

**能演示**：按热键 → 全屏变灰 → 框选 → 松手后 3 秒内出现任务树 → 顶栏出现卡片轮播 → 按完成 → 指针前进 → 关掉 DSH 重开，进度还在。

**验收**
- [ ] 全局热键与窗口内 Tab 双通道生效，且输入框内不抢 Tab
- [ ] 多显示器下框选层覆盖正确，高 DPI 不错位
- [ ] 视觉识别一次调用产出合法 `plan.set`（含目标与验收）
- [ ] 卡片左右滑动跟手，`node.advance` / `node.back` 行为符合 DATA-MODEL §4
- [ ] 进程被杀后重启，任务树与指针完全一致（回放校验）
- [ ] 截图清理策略生效

**退出条件**：一个真实任务能从"拍一张"走到"完成"，全程不用打字。

---

## P2 · 协作

**能演示**：停在某个节点时，侧边浮出 2 条 AI 建议；点「这部分交给你」，AI 反问确认后开工，卡片变「AI 正在做」，完成后变「待你确认」。

**验收**
- [ ] 建议按节点缓存，同节点不重复计费
- [ ] 交接五态迁移有单测，非法迁移被拒绝
- [ ] AI 产出写入节点档案 `nodes/*.md`
- [ ] 任务树可在工作台里增删改排序（复用同一套 Intent）
- [ ] 一次会话的 token 消耗可见

**退出条件**：人和 AI 能在同一节点上交替推进而不丢上下文。

---

## P3 · 抛光

**能演示**：装上就是最终观感。

**验收**
- [ ] 五条动效原则全部落地，`prefers-reduced-motion` 降级可用
- [ ] 离线态、重连态、空态、错误态全部有设计
- [ ] 设置页：热键（含裸 Tab 危险开关）、留存天数、模型、开机自启
- [ ] 托盘菜单、窗口位置记忆、多分辨率适配
- [ ] 安装包可分发（Windows NSIS + portable）

**退出条件**：陌生人拿到能自己装上并用起来。

## P4 · 生长

- 学习模式：识别 `concept` 节点，左/右浮出 tips 卡片，带「顺带一提」与衍生问题。
- 眼球追踪：新增 `IntentSource` 适配器，把凝视/停留映射为 `node.focus`，不改状态机。
- macOS 伴随层：复用协议，重写窗口与热键层。

## 风险台账

| 风险 | 影响 | 当前对策 |
|---|---|---|
| 裸 Tab 会吞掉全系统 Tab | 高 | 默认双通道；裸 Tab 藏进「我知道风险」开关 |
| 三端状态漂移 | 高 | 单写者 + 事件日志 + seq 校验，视图不得自改 |
| 截图隐私 | 中 | 默认 7 天清理，可关留存，面板明示路径 |
| 模型成本 | 中 | 建议缓存 + 分档模型 + 单次预算上限 |
| 长期可维护性 | 高 | 契约文档 + ADR + 每包 README + 单测闸门 |
